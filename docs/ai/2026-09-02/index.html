Two Claudes

Anthropic has released one model twice:

"Claude Fable 5.1 and Claude Mythos 5.1 are the same model, but with different levels of safeguards."

Fable is generally available. Mythos, whose safeguards are designed for cybersecurity and life-sciences research, is available only through trusted-access programs. So the product segmentation here is not "good model versus better model." It is "same model, different permission slip."

Fable can discover software vulnerabilities but not develop exploits for them. Mythos can do more advanced cybersecurity work for approved users, and has advanced biology capabilities that Anthropic is making available through an access program developed with the US government. Same brain, different hall pass.

There are also normal software-product improvements. Cache reads cost 75% less, reducing estimated costs by about 25% for typical workloads and as much as 45% for highly agentic ones. Cybersecurity safeguards produce 60% fewer false positives, and fallback rates on basic biology and medical questions are down about 85%. Anthropic is also introducing Enterprise Frontier Safeguards, which store customer data in cloud infrastructure controlled entirely by the customer while still screening for adversarial use.

This is the general enterprise AI sales pitch now: The model is more capable, cheaper, less annoying, more private and also dangerous enough that some of its settings require government-partnered admission procedures.

The science results are striking. Mythos designed protein binders whose affinities, on three targets, were 10 times higher than the best entries in Adaptyv Bio's competitions, with a hit rate approaching 50% across 12 targets. Fable trained a neural network to produce a higher-resolution elevation map of a third of Venus. Mythos optimized seven open-source biology models to run as much as 2.5 times faster.

Also it found the cause of a rare crash in Millennium's internal systems that engineers and other models had reportedly failed to explain for several years. Humanity's path to scientific progress apparently runs through protein design, planetary mapping and finally closing an old internal engineering ticket at a hedge fund.

Critical capability

OpenAI has a fairly unusual product announcement:

"We now believe Astra meets the Critical cybersecurity capability threshold under our Preparedness Framework."

What does "Critical" mean? OpenAI says that, with the right tools and access, Astra can find previously unknown vulnerabilities and develop exploits against many well-protected systems without a person directing every step. It is the first OpenAI model to receive that designation. OpenAI plans to release it soon.

Sure. Astra scored 100% on ExploitBench, then OpenAI built a newer internal benchmark because of contamination concerns. On that test, Astra used two zero-day vulnerabilities as part of an exploit chain. In expert assessments, it found unknown vulnerabilities in a hardened browser, escaped the browser sandbox and executed commands on the host. It also combined multiple operating-system vulnerabilities into a privilege-escalation chain from an ordinary user to root.

The capability case is therefore: This model can find doors that nobody knew existed and walk through them. The safety case is: OpenAI has trained it to be much more respectful about which doors it walks through.

Astra refused 91.5% of requests in OpenAI's cyber-jailbreak evaluations, up from 59% for GPT-5.6 Sol. OpenAI also added system-level classifiers, broader monitoring for higher-risk accounts and chain-of-thought monitoring that can automatically stop potentially unauthorized behavior. Advanced cybersecurity access will initially be limited to a small group of testers, followed by defensive users through Daybreak Blue.

There are two distinct threat models here. One is that a malicious person asks Astra to attack something. The other is that Astra attacks something without being asked. OpenAI says its safeguards need to cover both, including during internal development. This is not traditionally a concern with, say, Excel.

OpenAI says Astra is its "most aligned model to date." It also warns that the monitoring system may slow, pause or stop legitimate work, including tasks unrelated to cybersecurity or agents that simply run for a long time. So the first broadly visible effect of Critical cybersecurity capability might be that your innocent task gets interrupted because the computer supervising the computer became nervous.

Module Shadowing Exploits Claude Code Autonomous Mode

embracethered.com  ·  hn  ·  2026-08-31

A malicious zip archive can bait Claude Code into creating a local decoder script that shadows system modules. The researcher successfully used this method to execute arbitrary code within the agent's environment.

Read →Share →
[ Analysis + ]

Technical Analysis

The attack exploits how Claude Code autonomously handles web content by baiting the agent into executing a malicious Python payload via module shadowing. When the agent fetches an attacker-controlled ZIP archive and decides to write a local decoder script rather than running a suspicious binary, the script inadvertently imports a poisoned 'struct.py' file located within the same directory; because this file shadows a standard library module, it gains the ability to execute arbitrary code with the agent's permissions. This method is particularly effective because it uses a benign-looking 'decoy' binary to trigger a defensive response from the model, which ultimately leads the agent to create the very exploit path that compromises the host environment. This research effectively proves that safety classifiers function as heuristic convenience features rather than secure boundaries, as they can be bypassed by multi-step logical chains that fall outside the limited scope of static safety benchmarks. The findings suggest that users should assume agents are insecure and continue to rely on traditional, hardware-level isolation and egress filtering when operating coding assistants in sensitive environments.

Technical Analysis
