denoland/celld

self-hosted, distributed Durable Objects

Rust | 3,472 | 1,783 stars this week

1d on weekly

Analysis

`celld` is an open-source daemon designed to host Cloudflare Workers and Durable Objects on self-managed infrastructure. By embedding a V8 runtime, it enables developers to execute standard Wrangler bundles locally while using S3-compatible storage or Google Cloud Storage as the primary source of truth. The system achieves high availability and distributed state management without a centralized control plane or complex consensus protocols. Instead, it relies on object-storage compare-and-swap operations to assign cell ownership and continuously replicates SQLite databases to the bucket. This architecture ensures that cells are sharded by design, which limits the blast radius of failures and allows for efficient, inactive-state scaling.

This project is ideal for developers and organizations who want the portability and cost-efficiency of self-hosted Durable Objects without relying on a specific cloud provider's proprietary platform. It is particularly attractive for teams looking to avoid vendor lock-in while maintaining the developer experience of modern serverless runtimes. The project’s rising profile is driven by its innovative "no-consensus" approach to distributed systems, which significantly lowers the operational overhead of running stateful, sharded applications. By leveraging existing cloud storage buckets, `celld` simplifies the deployment of high-performance, consistent backend logic across private or hybrid cloud environments. Its focus on security, observability through diagnostic tools, and resource-aware memory shedding further distinguishes it as a robust solution for scalable, stateful services.
