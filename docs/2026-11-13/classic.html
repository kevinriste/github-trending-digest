10. tailscale/tailcat Not new today

like netcat, but over Tailscale's data plane, without Tailscale's control plane

Go | 9,185 | 173 stars today

First seen: November 13, 2026 | Streak: 1d

Analysis

Tailcat is an open-source, userspace networking tool that provides netcat-like connectivity over Tailscale’s encrypted data plane without requiring Tailscale’s control plane, accounts, elevated privileges, or changes to system routing and DNS. One side runs a listener and shares a short-lived tailcat address out of band, while the other uses that address to establish a connection. Built on Tailscale’s Magicsock and WireGuard components, it bootstraps through DERP relays, attempts NAT traversal for a direct peer-to-peer UDP connection, and falls back to relaying when necessary. The CLI and Go library support standard input/output piping, TCP port serving and forwarding, browser access, SSH with configurable public-key authentication, command execution, and exit-node-style access to selected network destinations. It also includes an experimental WebAssembly browser client and can use either public rate-limited DERP infrastructure or privately operated relays.

The project benefits developers, system administrators, support teams, and security-conscious users who need quick, encrypted access between machines without deploying a full VPN or exposing services publicly. It is useful for transferring data, debugging remote systems, reaching local web applications, forwarding databases or device ports, and providing tightly scoped SSH or command services. Its short-lived connection addresses, endpoint encryption, minimal host integration, and explicit local binding defaults make it convenient for temporary or ad hoc connectivity while reducing configuration overhead. Tailcat is likely trending because it combines familiar netcat-style workflows with modern NAT traversal and WireGuard security, while remaining lightweight, portable, and independent of a central account-based control plane. Its Go library, broad installation options, container and browser support, and alignment with growing interest in private peer-to-peer networking further expand its appeal.
