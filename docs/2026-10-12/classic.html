AirLLM is an open-source inference and training framework that enables very large language models to run on limited-hardware systems, including GPUs with only a few gigabytes of VRAM. It reduces memory requirements by splitting model checkpoints into layer-wise components and streaming them from disk or host memory to the GPU as needed, rather than loading the entire model at once. The project provides a unified `AutoModel` interface for many popular architectures, including Llama, Qwen, Mistral, DeepSeek, ChatGLM, and Mixtral. It also supports CPU inference, Apple Silicon through MLX, optional prefetching, FP8 and block-wise 4-bit or 8-bit compression, and selective expert loading for mixture-of-experts models. Recent functionality extends the same streaming approach to parameter-efficient training, keeping adapters on the GPU while frozen weights are loaded one layer at a time.

AirLLM is particularly useful for researchers, developers, students, and hobbyists who want to experiment with models that exceed their available GPU memory without relying exclusively on expensive cloud hardware. It can also benefit organizations seeking lower-cost local inference, provided they have sufficient storage and can tolerate the performance trade-offs of layer streaming. The project is trending because it presents a practical way to access rapidly growing models—such as 70B, 125B, 235B, and larger systems—on consumer-grade hardware.
