Foundry // Agent Foundry

Streamline LLM Interaction with ADHD-Focused Skill Plugins

github.com  ·  27,968 stars  ·  422 stars today

This plugin optimizes AI agent communication by stripping away conversational fluff and enforcing a strict, fact-first response structure. It effectively reduces cognitive load by prioritizing actionable solutions over lengthy preambles.

Read →Share →
[ Analysis + ]

ayghri/i-have-adhd ↗

Technical Analysis

The `i-have-adhd` repository provides a specialized skill plugin for coding agents, such as Claude Code and Codex, designed to optimize LLM responses for efficiency and clarity. By enforcing a strict set of ten rules—such as prioritizing immediate actions, utilizing numbered lists, and eliminating conversational filler like preambles or closers—it forces the AI to cut straight to the technical solution. Technically, the tool functions as a system-prompt modifier that can be installed directly through plugin marketplaces, requiring no local cloning to operate. Users can trigger this behavior explicitly via a command or allow the agent to invoke it implicitly when a task demands high-density information. Additionally, the plugin is highly customizable, allowing users to fork the repository and tweak the core operational rules in `SKILL.md` to suit their specific workflow requirements.

This project is primarily intended for developers who struggle with the verbose, conversational nature of standard AI assistants and prefer a streamlined, "just the facts" interaction model. It is gaining traction because it addresses a common pain point: the frustration of scrolling past excessive polite fluff to find the actual code or command required to solve a problem. By shifting the AI’s communication style to be task-oriented and objective, the plugin minimizes cognitive load and keeps developers in a state of flow. Its popularity highlights a broader movement toward "ADHD-friendly" computing, where users are actively seeking ways to reduce digital distractions and improve the precision of their productivity tools. Ultimately, it serves as an essential utility for anyone looking to maximize their development speed by stripping away unnecessary text.

cathrynlavery/diagram-design ↗

Technical Analysis

The `diagram-design` repository provides an AI-native design system for creating editorial-quality diagrams directly within coding environments like Claude Code, Pi, and Codex. It replaces generic, "slop-heavy" chart generators with 29 high-quality, self-contained HTML and SVG templates that prioritize clean typography and minimal, functional aesthetics. The tool works by mapping a user's website brand—including colors and font stacks—to semantic design tokens, ensuring every generated asset is visually consistent with the user’s existing design system. Beyond creating new diagrams from scratch, the system can parse and convert existing Mermaid or draw.io files into professional-grade visuals tailored to specific audiences, levels of detail, and screen sizes. By utilizing a local-first, dependency-free approach, it produces accessible, lightweight assets without the need for Figma or manual styling.

This project is primarily aimed at technical writers, software architects, and founders who want to produce polished, branded content without sacrificing time to tedious manual design tasks. It is particularly valuable for developers who struggle to balance high-velocity coding with the need for high-quality documentation or presentation graphics. The repository is trending because it solves the "generic AI diagram" problem by integrating seamlessly into the modern agentic workflow, allowing creators to iterate on architecture diagrams and flowcharts as easily as they commit code. By automating the transition from messy sketches to brand-aligned visuals, it enables professionals to maintain a high standard of editorial polish across their technical documentation and product decks with minimal effort.

github.com  ·  26,272 stars  ·  351 stars today

Read →Share →
[ Analysis + ]

openai/skills ↗

Technical Analysis

The `openai/skills` repository serves as a centralized catalog for "Agent Skills," which are modular collections of instructions, scripts, and resources designed to enhance the capabilities of AI agents. These skills allow developers to package specific task-oriented functionalities that agents can discover and execute in a repeatable, standardized manner. Technically, the repository utilizes a directory-based structure where each skill resides in its own folder, enabling seamless integration with the Codex environment. Users can manage these assets through a dedicated `$skill-installer` tool, which supports the installation of curated or experimental skills via local paths or direct GitHub URLs. Once installed, these skills are automatically recognized by Codex, allowing for a "write once, use everywhere" approach to agentic workflow automation.

This project is primarily intended for developers and teams looking to extend the utility of AI agents by incorporating custom, task-specific logic into their existing systems. It offers significant benefits to those who require a scalable way to distribute and maintain functional extensions across different projects without rewriting code. Although the repository is now deprecated in favor of the newer OpenAI Plugins framework, it remains a critical historical resource for understanding the foundational architecture of agent-based task management. It is often referenced by researchers and developers interested in the evolution of open standards for AI agent interoperability. By providing a clear template for modular AI capabilities, the repository continues to serve as an educational touchstone for building complex, instruction-driven AI workflows.

By treating video as a form of web composition rather than a traditional manual editing process, HyperFrames empowers users to scale their content creation efforts significantly. Read →Share →
[ Analysis + ]

obra/superpowers ↗

Technical Analysis

Superpowers is an agentic skills framework designed to standardize the software development lifecycle across various AI coding assistants, including Claude Code, Cursor, and the GitHub Copilot CLI. Technically, it functions as a modular plugin system that enforces a rigorous methodology—incorporating Socratic brainstorming, mandatory Test-Driven Development (TDD), and systematic task decomposition—before any code is written. By injecting a set of composable skills into the agent’s session, it compels the AI to create detailed implementation plans and perform autonomous, multi-stage code reviews. The framework relies on a structured workflow, such as subagent-driven development and git worktree isolation, to ensure that coding agents operate with persistence and architectural discipline. Ultimately, it shifts the agent's behavior from impulsive coding to a verified, process-driven execution model.

Software developers and enterprise engineering teams who struggle with the erratic, hallucination-prone, or ad-hoc nature of current AI coding tools will find this framework highly beneficial. It is trending because it addresses the core frustration of "agent drift," where AI models often lose context or ignore testing standards during complex multi-hour tasks. By imposing a professional, disciplined development process, Superpowers transforms high-level prompts into granular, testable, and reliable outcomes. It is particularly valuable for developers who want to scale the effectiveness of their AI assistants without abandoning strict engineering principles like YAGNI and DRY. As the landscape of AI-assisted coding shifts from simple autocomplete to autonomous agentic systems, this project provides the necessary governance to make such automation actually viable for production environments.

[ Analysis + ]

multica-ai/andrej-karpathy-skills ↗

Technical Analysis

The `multica-ai/andrej-karpathy-skills` repository provides a structured configuration file designed to optimize the performance of AI coding agents like Claude Code. By codifying specific observations from Andrej Karpathy regarding LLM behaviors, the project establishes four core principles: Think Before Coding, Simplicity First, Surgical Changes, and Goal-Driven Execution. These guidelines function by forcing the model to explicitly state assumptions, prioritize minimal code changes, avoid unsolicited refactoring, and focus on verifiable success criteria. Technically, the project is implemented as a reusable `CLAUDE.md` file that can be installed as a plugin in Claude Code or integrated as a Cursor rule via `.mdc` files. This framework effectively acts as a system prompt to constrain an LLM’s tendency toward over-complication and silent error-making.

Software developers and engineering teams who rely heavily on AI-assisted coding tools will find this repository highly beneficial for maintaining codebase hygiene and reliability. It addresses the common frustration of AI agents introducing bloated abstractions or unwanted side effects during seemingly simple tasks. The project is trending because it provides a practical, "plug-and-play" solution to a widely recognized industry problem: the difficulty of prompting models to act with the restraint and precision of a senior human engineer. By shifting the agent's focus from mere code generation to goal-oriented verification, users can achieve higher-quality output with significantly less manual oversight. Ultimately, it serves as an essential tool for those looking to standardize and elevate the behavior of autonomous coding agents across their development workflows.

[ Analysis + ]

microsoft/markitdown ↗

Technical Analysis

MarkItDown is a versatile Python utility developed by Microsoft designed to convert a wide array of file formats—including PDFs, Office documents, images, audio, and web content—into clean, structured Markdown. By prioritizing document hierarchy such as headings, tables, and lists, the tool generates output specifically optimized for ingestion by Large Language Models (LLMs) and automated text analysis pipelines. Technically, it functions as a modular converter that leverages local processing for basic tasks while offering optional integrations for cloud-based services like Azure Document Intelligence and Azure Content Understanding. The tool supports plugin architectures to extend its capabilities, such as adding OCR support for complex document analysis. Users can interact with the utility via a straightforward command-line interface or by integrating its Python API directly into their custom software projects.

This project is highly beneficial for developers and data engineers who are building RAG (Retrieval-Augmented Generation) systems or automated document processing pipelines. By transforming heterogeneous data into a token-efficient, LLM-friendly format, it significantly simplifies the challenge of feeding multi-modal information into AI models for summarization or analysis. The tool is trending because it addresses a critical bottleneck in the AI ecosystem: the difficulty of effectively parsing messy, proprietary file formats for machine consumption. Its ability to preserve document structure while bridging the gap between local files and advanced cloud-based analysis makes it an essential asset for modern AI-driven workflows. Consequently, it provides a practical, standardized solution for teams looking to streamline data preparation without reinventing complex parsing logic.

Shield // Privacy Shield

Stealth Web Navigation via Fingerprint-Spoofing Headless Browsers

github.com  ·  10,151 stars  ·  135 stars today

Camofox-browser circumvents modern bot detection by implementing low-level fingerprint spoofing within a specialized Firefox fork. It provides a hardened, efficient interface for autonomous agents to interact with protected websites without triggering automated traffic flags.

Read →Share →
[ Analysis + ]

jo-inc/camofox-browser ↗

Technical Analysis

Camofox-browser is a stealth headless browser specifically engineered for AI agents to interact with the modern web without being flagged as automated traffic. Unlike standard tools like Puppeteer or Playwright, which can be easily detected, this project leverages a custom fork of Firefox that performs fingerprint spoofing at the C++ level. By modifying core browser parameters—such as WebGL renderers, screen geometry, and hardware concurrency—it bypasses sophisticated bot detection mechanisms like Cloudflare and Google’s anti-scraping filters. The browser is wrapped in a REST API that optimizes web interaction by providing lightweight accessibility snapshots, stable element references, and built-in search macros. Furthermore, it supports essential agent workflows such as session isolation, proxy routing, and automated YouTube transcript extraction, all while maintaining a minimal memory footprint.

This project is highly beneficial for developers and organizations building autonomous AI agents that require reliable, authenticated access to real-world websites. It solves a critical bottleneck in AI development: the high failure rate of automated browsers when navigating sites protected by robust security layers. The solution is trending because it provides a drop-in, efficient alternative that allows agents to operate at scale on cost-effective infrastructure like Raspberry Pis or low-cost VPS providers. By offering features like structured JSON extraction and session tracing, it streamlines the integration of live web data into AI workflows. Ultimately, it empowers developers to focus on building intelligent agent logic rather than continuously fighting against increasingly aggressive bot detection systems.
