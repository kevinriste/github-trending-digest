The classifier returns.

Here is a good way to save millions of dollars on artificial intelligence: Stop using a general-purpose language model for a task that does not require language.

Amazon had Claude Sonnet 4.6 labeling tickets in an internal system. Each ticket had to be placed into one of 20 categories. Sonnet received a long prompt, reasoned about the ticket and generated a JSON response. This worked well, but apparently Amazon has quite a lot of tickets, so "worked well" also meant roughly $22,200 per million tickets.

Then two engineers replaced Sonnet with Strands Decider, a 2 billion parameter decision model that cannot generate text. You give it some information and a fixed set of options, and it returns probabilities and a confidence score. Strands says the replacement performed as well as Sonnet at about 98% lower cost:

A decision model can't generate text. It's first given some state and a question with a set of options, then the decision model returns a probability for each option plus a confidence score. We saw this method fit perfectly with ticket labeling: the state is the ticket, the options are the label catalog.

Right. Sonnet was being asked to read a ticket and produce an eloquent little machine-readable essay whose essential content was "category 7." Strands Decider just says "category 7." The main cost saving came from noticing that Amazon did not need the essay.

Sonnet consumed an average of 6,554 input tokens and 170 output tokens per ticket. Strands Decider used 2,009 input tokens and one output. It cost about $500 per million tickets rather than $22,200, and ran much faster. At enough scale, removing 169 unnecessary tokens from every answer is apparently worth millions of dollars.

This is in some sense the return of ordinary machine learning. The recent theory of software has been that every problem can be solved by sending a long paragraph to a giant language model. The slightly newer theory is that some problems are multiple choice. If the task is "pick one item from this stable catalog," it might be useful to have a machine whose entire personality is picking one item from a stable catalog.

There was one complication:

One thing that surprised us was that JSON key order changed the answer. Sending the same content with keys in a different order moved the output probabilities by up to 0.19. We now send every request with sorted keys.

The model can categorize security findings and customer escalations at enormous scale, but it feels differently about the facts depending on whether they are alphabetized. Fine. The future of enterprise AI is cheaper, faster and extremely particular about JSON key order.

Fable and Mythos.

Anthropic has introduced Claude Fable 5.2 and Claude Mythos 5.2, which it says have designed three working electronic devices, solved two open problems in black-hole physics and formalized Fermat's Last Theorem in 30 hours.

For most coding and knowledge tasks, Anthropic recommends starting with Opus 5.5.

Sure. Fable and Mythos are for "the most ambitious, open-ended technical work." If you merely need to write software, use the daily driver. If you need to settle a question in quantum gravity, move up one tier.

Fable and Mythos are actually the same underlying model. Fable has cybersecurity and biology safeguards and is available to everyone. Mythos has broader capabilities in those areas and is available to approved organizations through Anthropic's verification programs. The product differentiation is not intelligence but permissions. Fable is the model after compliance has reviewed it; Mythos is the same model with a badge that opens the laboratory door.

The scale of some of the demonstrations is also striking. One Fable experiment used more than 1,000 subagents for eight days to build a prototype operating system from an empty folder. Another used a team of 1,000 agents to formalize Fermat's Last Theorem in 30 hours. Calling this "a model" feels increasingly imprecise. It is a model in roughly the sense that a company is one legal person. You ask it to prove a theorem, and it assembles a thousand-worker organization.

Anthropic also says that "over 90% of the changes merged into Anthropic's core codebase are now written by Claude," with human guidance. So Claude helps write Anthropic's software, Anthropic uses that software to build better Claude models, and the better Claude models write more of Anthropic's software. The humans provide guidance and, presumably, merge permissions.

The new models cost $8 per million input tokens and $40 per million output tokens. An optional fast mode generates tokens up to 2.5 times faster and costs twice as much. Fable can solve open problems in black-hole physics, but it cannot solve rush pricing.

Amazon Cuts Classification Costs by 98%

strandsagents.com  ·  368 pts  ·  126 comments

For a fixed 20-category ticket queue, Amazon swapped a general-purpose model for a compact decision system. Latency fell 78%, token use fell 70%, and estimated cost dropped from $22,200 to $500 per million tickets.

Read →Share →
[ Analysis + ]

Technical Analysis

Amazon engineers replaced Claude Sonnet 4.6 with Strands Decider E4B for large-scale internal ticket classification across 20 fixed categories. Deployed on a SageMaker GPU endpoint and integrated with SQS, Lambda, AppConfig, and CloudWatch, the decision model returned label probabilities rather than generated explanations, reducing latency by 78% and token usage by 70% while matching or exceeding Sonnet’s accuracy. The change lowered estimated costs from about $22,200 to $500 per million tickets, or roughly 98%, while also shortening Lambda execution times. The approach is most suitable for high-volume, closed-set classification tasks with compact context, and the team reduced rollout risk by comparing both systems in production through a configurable three-way switch.

Fossil CO₂ Emissions Dip, but the Peak Waits

news.exeter.ac.uk  ·  25 pts  ·  14 comments

The Global Carbon Project forecasts a 0.4% decline in fossil-fuel emissions in 2026, as clean energy and electric vehicles meet more demand. Total emissions still rise when land-use change is included, leaving the long-term trajectory unresolved.

[ Analysis + ]

Technical Analysis

The Global Carbon Project forecasts that fossil-fuel CO₂ emissions will fall 0.4% in 2026 to 38.2 billion tonnes, largely because solar, wind and electric vehicles are meeting much of rising energy demand, while oil use also drops amid the Iran-related energy shock. The decline is uneven—China, the US, the EU and Japan are expected to reduce emissions, while India’s rise offsets some gains—and coal emissions still increase slightly. Land-use emissions are projected to rise, pushing total CO₂ emissions to 43.3 billion tonnes, while atmospheric concentration reaches about 427.7 ppm. Researchers stress that a one-year decline is not yet a durable peak: faster deployment of clean technologies, protection and expansion of natural carbon sinks, and broader carbon removal are needed, especially with the remaining 1.5°C carbon budget estimated at fewer than four years of current emissions.

Technical Analysis

The article demonstrates that ordinary broadcast TV signals can detect movement through walls by analyzing how a person’s reflections interfere with the direct signal, producing frequency-dependent fading patterns. Measuring the timing between these changes allows the author to estimate walking speed using a simple radio receiver and known signal frequency. The same principle can be applied to other wideband signals such as Wi‑Fi and LTE, potentially enabling low-cost motion sensing without dedicated radar hardware. This is important both for practical applications in monitoring and occupancy detection and for privacy, since ubiquitous wireless transmissions can reveal activity beyond a receiver’s line of sight.
