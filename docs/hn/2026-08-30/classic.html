The HN Take

Straight lines

Here is a geography problem:

There has been some interest in determining the longest distance one can sail on the earth without hitting land, as well as in the converse problem of determining the longest distance one could drive without encountering a major body of water.

The sailing question apparently began with a 2012 Reddit post proposing a straight path from Pakistan to eastern Russia. This "generated a lot of interest and led to subsequent attempts to prove and disprove the user," because sometimes the peer-review process begins on r/MapPorn.

The difficulty is that "straight" on Earth means following a great circle, while Earth inconveniently contains islands, lakes and "the fractal nature of the coasts." At one arc-minute resolution, an exhaustive search would require considering 233,280,000 great circles and checking more than 5 trillion points. You ask "how far can I sail without turning," and pretty soon you are doing spherical trigonometry and global optimization because there might be a tiny island in the way.

The researchers instead used a branch-and-bound algorithm. They classified every positive-altitude point as land and every negative-altitude point as water, with zero treated conservatively against whichever path they were searching for. This is not strictly how geography works, but it is how optimization works: First simplify the planet, then prove the Reddit guy right or wrong.

Error reporting

Qubes OS is designed around isolating activity into separate virtual machines called qubes, while keeping the highly trusted administrative domain, dom0, away from untrusted inputs. Here is one untrusted input it did accept:

If qvm-copy-to-vm is used to copy a file from dom0 to a malicious qube, that qube can inject an arbitrary command into dom0.

The file-transfer protocol sends a confirmation from the destination qube back to dom0. If there is an error, that confirmation includes the name of the affected file, as reported by the destination. Dom0 sanitizes the filename by removing non-ASCII characters and double quotation marks, but leaves shell metacharacters in place. It then constructs an error-dialog command containing the filename and executes it using system().

So the security architecture carefully isolates the malicious virtual machine from the most trusted part of the operating system, except that when a copy fails, the trusted part asks the malicious machine what went wrong and runs its answer in a shell.

The attack requires a compromised qube and a user-initiated copy from dom0 into that qube, so this is not a drive-by compromise. Still, error reporting is traditionally supposed to tell you that something bad happened, not become the bad thing itself. The fix is included in an update. Continue updating normally; no special ritual is required.

1. Longest Straight Line Paths on Water or Land on the Earth (2018)

arxiv.org | joebig | 59 points | 13 comments | discussion

First seen: August 30, 2026 | Consecutive daily streak: 1 day

Analysis

This 2018 research paper by Rohan Chabukswar and Kushal Mukherjee addresses the computational challenge of identifying the longest possible straight-line paths for travel on Earth without hitting land (for sailing) or water (for driving). Due to the complexity and geographic irregularities of coastlines, the authors utilized a branch-and-bound optimization algorithm applied to the ETOPO1 Global Relief Model. This methodology successfully confirmed a 32,090-kilometer sailable route from Pakistan to Russia, originally popularized on Reddit, and identified a corresponding 11,241-kilometer drivable path spanning 15 countries. By formalizing this recreational problem as a rigorous mathematical exercise, the study demonstrates how systematic optimization techniques can resolve complex geographic constraints efficiently.

2. Arbitrary code execution in QubesOS via copy-to-VM error reporting backchannel

qubes-os.org | vntok | 35 points | 8 comments | discussion

First seen: August 30, 2026 | Consecutive daily streak: 1 day

Analysis

Qubes Security Bulletin 118 addresses a critical arbitrary code execution vulnerability in the `qvm-copy-to-vm` tool, which allows a compromised qube to gain control of Dom0 by injecting malicious commands into error reporting messages. The flaw exists because the sanitization function fails to strip shell meta-characters from filenames, which are subsequently passed to the `system()` function in Dom0. Because this permits an attacker to execute commands with administrative privileges during a routine file transfer, it represents a significant security risk for the entire Qubes OS ecosystem. Users are advised to install the latest security updates via the standard Qubes update tool to mitigate this vulnerability.

The reaction was broadly positive toward Qubes’ isolation model, with commenters valuing its security benefits despite usability and compatibility drawbacks. The main disagreement concerned implementation and architecture, particularly the handling of attacker-controlled data in Dom0 and the use of system(). A smaller discussion addressed the practical impact for ordinary users, hardware acceleration, and possible KVM-based alternatives.

Analysis

California lawmakers have unanimously passed Assembly Bill 1856, which officially exempts open-source operating systems from the state's upcoming Digital Age Assurance Act. By redefining "operating system provider" to exclude software distributed under common licenses like the GPL, MIT, BSD, and Apache, the amendment ensures that Linux distributions and similar platforms are not required to implement mandated age-verification protocols.
