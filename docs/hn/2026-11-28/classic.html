Linux in the browser

Here is a website:

"unkernel: real Linux, in your browser."

Specifically, it downloads a 3.6 MiB WebAssembly kernel, allocates 2,048 MiB of memory and boots an unmodified Debian aarch64 user space inside the browser tab. It has persistent storage, networking, Wayland applications, multiple terminals and suspend and resume. You can also run a web server inside the guest and open it "in a window over the terminal or a tab of its own while this page stays open."

Sure. The old model was that your computer ran an operating system, and the operating system ran a browser, and the browser displayed websites. The newer model is that your computer runs an operating system, which runs a browser, which opens a website, which runs an operating system, which runs a web server, which serves a website back to the browser. Eventually you will open that website and run another copy of Linux inside it, at which point the stack can continue until the laptop gets warm.

There is a familiar idea that the browser has become the operating system because people do all their work in web applications. This is metaphorically true. Unkernel's contribution is to make it less metaphorical. The browser did not replace Linux. It put Linux in a tab.

Residual attention

The standard transformer residual connection is pleasingly simple. A layer does some complicated computation, and then the model adds the layer's input back to its output so the original information does not disappear. This helps deep networks train, but after enough layers the model is adding together so many representations that useful early details can become diluted. The information is preserved in the sense that every document in the filing cabinet has been shredded into the same box.

Google Research's DeepCrossAttention tries a more selective approach:

"Rather than passing all prior layers forward with equal weight, DCA introduces a lightweight, layer-wise module that decides how to best combine previous embeddings on a per-token basis."

That is, transformers use attention to decide which tokens matter, and now they can use attention to decide which previous layers matter. Attention has discovered management.

Google says DCA reached standard-transformer performance in up to five times fewer training steps on two language-modeling datasets, and that a 30-layer DCA model beat the perplexity of a fixed-width standard transformer that needed 42 layers. The added parameters were less than 0.2% of the model, and DCA can be retrofitted onto an already trained transformer rather than requiring training from scratch.

The broad economic story of AI is that everyone needs extraordinary amounts of compute because models are enormous and inefficient, so the world must build vast data centers. The broad technical story of AI is that researchers keep finding small architectural changes that make the models less inefficient. These stories are not actually contradictory. If models become three times faster, the industry will probably not use one-third as many chips. It will run three times as many models and announce a chip shortage.

2. Unkernel: Real Linux kernel, compiled to WebAssembly

unkernel.dev | nreece | 380 points | 99 comments | discussion

First seen: November 28, 2026 | Consecutive daily streak: 1 day

Analysis

Unkernel is an open-source project that compiles a real Linux kernel to WebAssembly, allowing an unmodified AArch64 user space and Debian-like environment to run inside a browser tab. It provides a virtual machine with persistent browser-backed storage, graphical applications, terminals, and guest web servers exposed through browser windows. The system combines Linux-WASM, Emscripten, Mesa/virglrenderer, Wayland, and related browser virtualization components, with development sponsored by Vercel. Its significance is demonstrating that increasingly complete Linux environments can run portably in browsers without native installation, while still depending on browser memory, performance, and security constraints.

4. Google's DeepCrossAttention achieves comparable model quality up to 3x faster

research.google | ComputedCamp995 | 447 points | 161 comments | discussion

First seen: November 28, 2026 | Consecutive daily streak: 1 day

Analysis

Google Research introduces DeepCrossAttention (DCA), a transformer architecture that replaces fixed residual addition with token-specific, depth-wise cross-attention over prior layers, allowing models to selectively retrieve useful representations instead of diluting them through repeated summation. The lightweight routing mechanism adds less than 0.2% parameters while reportedly reducing required depth and training steps, reaching comparable quality up to several times faster and using 30–40% fewer parameters in some tests. On language and vision benchmarks, DCA improved convergence, perplexity, and training stability, and it could also be retrofitted onto pretrained transformers with limited further training. The work is part of a broader industry trend toward dynamic residual routing, including attention residuals and hyper-connections, aimed at improving model efficiency and scaling without simply making models larger.
