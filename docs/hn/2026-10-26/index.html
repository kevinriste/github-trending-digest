Switzerland

You can now buy Switzerland for 15 Swiss francs:

"Every block is one metre. Terrain, glaciers, lakes, forests and dams come from swisstopo's open geodata. The Matterhorn is exactly as tall and as steep as the real one."

This is Switzerland recreated at 1:1 scale in Minecraft. It covers 41,285 square kilometers, takes up 24 gigabytes as a download and about 60 gigabytes on disk, and reaches 4,634 blocks at the summit of the Dufourspitze. The whole country costs 15 francs, though the Jungfrau-Aletsch region is free, presumably as a sort of alpine due-diligence room.

The pitch is compelling. Real Switzerland is famously expensive and difficult to alter. Minecraft Switzerland is 15 francs, comes with shaders and lets you fly at up to roughly one kilometer per second. If you dislike the view from your house, you can put another house on top of it. If you dislike the commute from Geneva to Zurich, you can teleport. This is what digitization is supposed to do: preserve the mountains while eliminating Swiss real estate prices.

There are qualifications. It is "1:1 scale, not a 1:1 copy." Buildings are simplified, bridges and roads can be wrong or missing, and the world "has been checked by sampling, not metre by metre." Beyond the Swiss border, the data are coarser, and "where building data is missing, trees stand in place of houses, for example near Geneva."

Sure. Inside Switzerland, meticulous federal geodata. Outside Switzerland, perhaps some trees. An admirably Swiss representation of the world.

Also, for legal reasons, the full version is sold only to Swiss residents. Everyone else can download the free UNESCO area, but only people who live in Switzerland can own all of Minecraft Switzerland. Even the simulated country has residency restrictions.

Local PDFs

Here is a modern software product:

PaperPilot is a PDF toolkit written in Rust that runs as an MCP server, command-line tool, browser app, desktop app and local REST API. It can merge, split, rotate, compress, OCR, watermark and sanitize PDFs, among other things. "No Chromium, no C++ runtime, no cloud calls."

The obvious use case is telling an AI agent, "Merge these two PDFs and compress the result," while keeping the files on your own machine. This is a useful division of labor. The AI provides natural-language instructions; a small local program does the actual document manipulation. The model does not need to become a PDF engine, and your tax returns do not need to visit a startup's server so that page 4 can be rotated 90 degrees.

PaperPilot says its browser version processes files in browser memory and invites users to open the Network tab to verify that there are no uploads. This is perhaps the purest contemporary trust model: Don't trust us, watch the packets.

The current release advertises a long list of features, while the benchmark section says, "TODO: add a real table." That's also a useful software benchmark. It can process your PDF locally, privately and in several different interfaces. How fast? Locally, privately and eventually.

This Minecraft world turns government geodata into a navigable country at true one-metre scale. Glaciers, forests, roads, and buildings emerge from a demanding pipeline of terrain data, procedural generation, and local compute.

[ Analysis + ]

Technical Analysis

The project recreates Switzerland in Minecraft Java Edition at true 1:1 scale, with each block representing one metre and terrain, glaciers, water, forests, infrastructure, and buildings generated from Swiss government and research geodata. It uses Minecraft 1.12.2, the Cubic Chunks mod, and substantial local resources: the full country download is 24 GB and requires about 16 GB of system memory, while terrain is generated as players explore. A roughly 2,400-square-kilometre Jungfrau-Aletsch section is free to try, while the complete Swiss map costs 15 CHF for Swiss residents and includes future updates, though it is early access and contains inaccuracies and lower-detail border areas. The project is notable as an ambitious demonstration of converting open geospatial datasets into a navigable, geographically faithful game world rather than manually building a Minecraft replica.

PaperPilot Keeps PDF Workflows Close

github.com  ·  151 pts  ·  44 comments

PaperPilot is a pure-Rust PDF engine exposed through a CLI, APIs, desktop software, WASM, and an MCP server. Files stay local or in browser memory while scripts and agents merge, OCR, sanitize, and transform documents without a cloud upload.

Read →Share →
[ Analysis + ]

Technical Analysis

PaperPilot is an open-source PDF and document toolkit built in pure Rust, offering a shared engine through a CLI, MCP server for AI clients such as Claude and Cursor, local REST API, desktop application, and browser-based WASM tools. It supports operations including merging, splitting, rotating, compressing, OCR, text extraction, watermarking, sanitization, and spreadsheet conversion, with files processed locally or in browser memory rather than uploaded to a cloud service. The project emphasizes privacy, portability, and reduced runtime dependencies, while making PDF workflows accessible to both automation scripts and AI agents. Its Apache 2.0 Community Edition is available for download or self-hosting, though several advanced conversion, editing, signing, and rendering features remain on the roadmap.

Technical Analysis

Simple Rules Grow Surprisingly Convincing Trees

brashandplucky.com  ·  74 pts  ·  9 comments

A procedural tree model lets buds compete for light, distribute resources, and survive across simulated seasons. Later passes add thickness, sag, bark, foliage, and level-of-detail geometry, turning biological rules into varied real-time forms.

Read →Share →
[ Analysis + ]

Technical Analysis

The article describes a procedural tree-growth system based on the self-organizing tree models of Palubicki et al. (SIGGRAPH 2009), in which buds compete for light and receive growth resources over successive simulated seasons. It models light with voxelized shadows, distributes resources through the branching structure, chooses shoot directions and phyllotaxis patterns, and removes poorly lit branches. After growth, separate procedures add branch thickness, sag, bark geometry, foliage cards, and level-of-detail representations for real-time or forest rendering. The approach is important because it produces varied, plausible tree crowns from simple biological rules while supporting efficient visualization and large-scale scene generation.

Keybytes turns a keyboard into a field of magnetic, individually addressable one-unit modules. Each key carries its own switch, RISC-V microcontroller, and power connections, while open schematics and firmware invite experimentation beyond conventional layouts.

Technical Analysis

Keybytes is an open-source modular keyboard whose individual 1u keys can be rearranged and connected through magnetic cases and pogo pins. Each key contains a Cherry MX switch, a CH32V003 RISC-V microcontroller, and power/I²C connections, while a separate STM32WB55 main board provides Bluetooth, USB-C, battery charging, storage, and firmware programming. The project includes KiCad schematics and PCBs, Onshape case designs, firmware-related infrastructure, and an MIT license, making it reproducible for hardware enthusiasts rather than merely a product demonstration. Its significance is the unusually fine-grained modular architecture, which explores customizable keyboard layouts and distributed electronics at the cost of greater component count and manufacturing complexity.

Technical Analysis

Charlie Gerard built Overgrown, a Chrome extension that treats neglected browser tabs like abandoned buildings by covering them with increasingly dense animated plants. Each tab has a neglect timer that pauses when viewed, and once vines exceed 5% coverage they block interaction until users remove them by dragging a selected machete, chainsaw, or flamethrower across the overlay. Technically, the extension uses a background worker to track tabs, a content script and SVG assets for plant and weapon animations, and a popup interface for settings and tab status. It is a small, playful productivity experiment that makes tab management more engaging without forcibly closing tabs or claiming to solve tab overload.
