The HN Take

Patent peace

Here is a nice way to announce that two giant technology companies have agreed not to sue each other quite so much:

Huawei and Qualcomm today announced a multi-year, broad patent license agreement that includes cross licenses to the companies' patent portfolios across a range of technology fields, including 5G, compute, AI, and networking, together with Qualcomm's purchase of certain Huawei U.S. patents in the areas of compute, AI, networking, and other technologies.

The agreement also "demonstrates the value of Huawei's innovations," "reaffirms industry recognition of Qualcomm's 5G technology leadership" and reflects each company's recognition of the other's continued innovation. Everyone is foundational, everyone is a leader, everyone owns patents that everyone else needs. Congratulations to all involved.

The basic business of telecommunications patents is that thousands of inventions have to work together in one phone, so thousands of exclusive legal rights have to be turned into permission. Huawei and Qualcomm each own enough of those rights that the practical solution is a broad cross license: Huawei can use Qualcomm's technology, Qualcomm can use Huawei's technology, and both can continue explaining that their respective technology made modern communications possible.

Qualcomm is also buying certain Huawei US patents, subject to regulatory approval. A patent is a government-granted right to stop other people from practicing an invention. A cross license is an agreement not to do that. The culmination of decades of fundamental research is that everyone gets together, praises everyone else's fundamental research and signs paperwork allowing the products to continue working.

Agent protection

Here is an argument for giving an AI agent access to your computer: Someone else might already have access to your computer.

A high-severity macOS screen-sharing vulnerability was actively exploited on systems with port 5900 exposed to the internet. Attackers could get root access and install a Monero miner. One affected machine was an always-on Mac Mini running Claude and Codex. Claude noticed suspicious files, sent an "URGENT" notification, stopped executing commands and helped trace and remove the malware before the machine was wiped.

The agent had extensive access to the computer, which is scary. This allowed it to notice that an attacker had even more access to the computer, which was useful.

Apple, meanwhile, is worried about agents. It plans additional controls around Full Disk Access because AI agents can expose "files, mail, messages, and even browsing history." Fair enough. But the Mac Mini's owner needed screen sharing partly because macOS permission prompts appear in a protected graphical layer that agents cannot see. Programs silently fail, the agent does not know why, and the human has to connect remotely and click "OK." So the security system encouraged persistent use of the screen-sharing system, and then a vulnerability in the screen-sharing system gave an attacker root access. Layered security.

What I didn't understand is that this setting does not in fact apply to most security updates. CVE fixes almost always arrive in point releases; in fact, the most recent point release was about fixing this bug.

The computer was configured to "Install...security updates automatically," but the security fix arrived as a point release that was not automatically installed. Apple is extremely particular about whether a program may access your Downloads folder, but somewhat more interpretive about whether a security update is a security update.

The broad philosophical dispute is straightforward. Apple thinks that powerful software should require explicit human permission to access sensitive parts of the computer. The user thinks that, having explicitly asked Apple to install security updates automatically, Apple should install the security updates automatically. Both sides want informed consent. They disagree about which consent counts.

First seen: October 05, 2026 | Consecutive daily streak: 1 day

Analysis

Denmark’s Central Person Register (CPR) reports that unauthorized parties exploited a Danish company’s legitimate, authorized access to obtain names, addresses, CPR identification numbers, and other personal data for approximately 8.8 million registered residents. People with protected names and addresses were reportedly excluded from that portion of the exposure. Authorities have revoked the company’s access, are investigating how the misuse occurred with security specialists and relevant agencies, and have notified the Danish Data Protection Authority and police. 6. We ported the original Doom to SQL

cedardb.com | Vaslo | 139 points | 20 comments | discussion

First seen: October 05, 2026 | Consecutive daily streak: 1 day

Analysis

CedarDB’s Vaslo describes porting the original 1993 Doom’s game logic, BSP-based renderer, and multiplayer state entirely into SQL, with Python limited to input, timing, and displaying returned bitmaps. The implementation stores WAD geometry and game entities in relational tables, runs gameplay at Doom’s original 35 Hz, and generates complete 320×200 frames through complex queries and window functions, reaching roughly 60 FPS on a modern laptop. The project demonstrates that set-based database operations can express sophisticated game systems, AI, animation, and rendering, while also making game data easy to inspect and modify. Its practical significance is limited—SQL is an inefficient choice for rendering—but the work illustrates how relational modeling, query optimization, and database concurrency can support an unusual multiplayer game server.
