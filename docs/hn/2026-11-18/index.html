Reasoning downhill

A standard problem with AI reasoning is that the model does not know when it is done. It thinks for a while, gets an answer, thinks some more, perhaps talks itself out of the answer, reads the same thing again, and eventually stops because someone set a token limit. Very human, but expensive.

Researchers from Duke, UIUC and Harvard propose a more directed approach called Energy-Based Reasoners. The model learns an energy function over its latent reasoning states, then improves its answer by moving downhill:

"Lower means better compatibility."

The score tells the model how good its current state is, the gradient tells it which direction to improve, and a small gradient tells it to stop. Instead of repeatedly asking "am I done yet?" in natural language, it reaches the bottom of a mathematical hill and goes home.

This apparently works well on algorithmic puzzles. A 1.8 million parameter model achieved 99.9% accuracy on Sudoku-Extreme using 345 times less inference compute than the next-best model. It also found a broad range of valid solutions to N-Queens and graph-coloring problems while maintaining near-perfect single-sample accuracy.

There is an intuitive lesson here. Existing recurrent reasoners loop without "any explicit assessment" of whether the loop is helping. The energy-based version has a numerical measure of progress and can stop when progress stops. A surprising amount of intelligence might consist of knowing whether your next thought will improve on your last one. A surprising amount of inference spending might consist of not knowing that.

Java memory safety

Java is memory-safe, except for the parts of Java that are written in hand-rolled assembly to decode Base64 faster. Calif researchers disclosed Java4Shell, a critical OpenJDK vulnerability that they say can be triggered by 64 A characters followed by an equals sign.

OpenJDK uses specialized AVX-512 instructions to accelerate Base64 decoding. For the malformed 65-character input, it allocates a 50-byte result array, miscalculates a negative output length and performs a 64-byte write, sending 62 bytes beyond the array. Java rejects the malformed input eventually, but only after corrupting neighboring memory. Security is all about the order of operations.

The researchers say they demonstrated remote code execution in default configurations of Keycloak, Jira, Confluence, Artifactory, Jenkins and PingFederate, among other products. A Java client can also allegedly be compromised merely by opening a TLS connection to a malicious server.

The nice idea of Java is that application developers do not have to worry much about memory corruption because the runtime handles memory safely. The less nice idea is that the runtime itself wants Base64 decoding to be extremely fast, so it uses unsafe low-level code. Most applications probably do not urgently need hand-optimized assembly to decode a few hundred bytes, but they receive the optimization, and its vulnerability, anyway. Write once, overwrite adjacent memory everywhere.

Calif says AI helped find the bug in an hour and produce the first working exploit two hours later, at a token cost below $200. Its proposed response is "vibe-uncoding": use AI not only to generate more software, but to find unnecessary features and delete them. AI makes it dramatically cheaper to discover obscure vulnerabilities. Ideally it will also make it cheaper to remove the obscure code that contains them. First the centaur hacker breaks Java; then the centaur maintenance engineer asks why Java needed that code in the first place.

Reasoning Model Claims 385× Less Inference

energy-based-reasoners.github.io  ·  52 pts  ·  4 comments

Energy-Based Reasoners refine solutions by following an explicit energy landscape rather than looping blindly. On demanding synthetic puzzles, a 1.8-million-parameter model reaches striking accuracy with dramatically reduced inference compute; broader tests remain ahead.

Read →Share →
[ Analysis + ]

Technical Analysis

The paper introduces Energy-Based Reasoners (EBRs), recurrent reasoning models that learn an energy function over latent states and use its gradient to refine solutions, select among candidates, and decide when to stop. This addresses a limitation of existing looped reasoners, which repeatedly update representations without an explicit measure of progress or solution quality. On algorithmic benchmarks, the 1.8-million-parameter EBR reportedly reaches up to 99.9% Sudoku-Extreme accuracy with far less inference compute than comparable models, while also achieving strong single-sample accuracy and multi-solution coverage on N-Queens and graph coloring. The results are important because they suggest energy-based objectives could make iterative reasoning more compute-efficient and controllable, though the evidence currently comes from narrow synthetic tasks rather than broad real-world applications.

Technical Analysis

The article describes an experiment using AI to audit theoretical astrophysics literature: it mapped 158,059 papers and 554,670 citations, screened 50,269 full texts, and used computational checks on 659 influential papers.
