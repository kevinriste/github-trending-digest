Failfs.

Linux 7.3 is out:

"This release is a record-breaker on all fronts; it brought in 18,765 non-merge commits from 3,021 developers, 807 of whom were first-time kernel developers."

There are significant group-scheduling improvements, virtual-machine working-set tracking, SMB server improvements and "the new failfs filesystem that fails all operations."

Sure. Most filesystems are judged by how reliably they complete operations. Failfs has simplified the problem by deciding in advance that it won't. You ask it to read a file, it fails. You ask it to write a file, it fails. There is presumably not much ambiguity about whether it is working correctly. If your normal filesystem fails all operations, you have an outage; if failfs fails all operations, ship it.

The release itself was similarly uneventful. "Nothing very special seems to have happened this last week," so version 7.3 arrived on Sunday as expected. The 7.4 merge window opens Monday, except the maintainer is on vacation and plans to spend much of the day "on a boat and under water."

This is a reasonable software release process. The record-breaking kernel came out on time because nothing happened, the next one will begin after some scuba diving, and one of the major new features is a filesystem that cannot do anything. Will wonders never cease?

Latent agents.

Here is one way to make artificial intelligence cheaper: Stop making it explain itself constantly.

A new paper on "Hybrid Reasoning Agents" proposes agents that alternate between ordinary text and continuous hidden-state reasoning. The agent thinks internally in latent space, then switches back to text when it needs to call a tool or interact with the outside world:

"HybridAgent shifts more internal reasoning into semantically rich and interpretable latent thoughts, while reserving text for external inspection and tool interaction."

This is basically how people work. You do not narrate every intermediate thought aloud while deciding whether to look something up. You silently think for a bit, then type a search query. Modern language-model agents, by contrast, have traditionally had to write themselves a little essay before using the calculator. This is expensive because the calculator does not care about the essay.

The researchers added a "HybridLink" that maps the model's last-layer hidden states back into its input embedding space, allowing it to continue thinking without decoding every step into tokens. They trained versions based on Qwen3 models at three sizes and report an average 10.4% performance improvement, 35.5% to 54.7% lower token usage, 1.8 to 2.6 times faster inference and 2.7 to 3.7 times lower cost across 11 benchmarks.

Also the latent thoughts are apparently inspectable:

"Surprisingly, we find that HybridAgent can render its thoughts in latent mode as human-readable pseudo-text."

The pitch for latent reasoning is that the model can think in its "own language" without laboriously translating everything into words. The pitch for this particular latent reasoning is that its own language still looks enough like words for humans to read it. The model has developed an efficient private language, but compliance can review the transcripts. Ideal corporate communication technology.

Hybrid Agents Reason Quietly, Then Act in Text

arxiv.org  ·  406 pts  ·  199 comments

A new architecture alternates between latent internal states and visible text-based tool use.

Across 11 benchmarks, the authors report lower token consumption and faster inference while leaving open a scholarly question: how much oversight depends on seeing the reasoning trace?

Read →Share →
[ Analysis + ]

Technical Analysis

The paper introduces HybridAgent, an LLM-agent architecture that alternates between text generation for tool calls and external oversight and continuous latent states for internal reasoning. Its HybridLink adapter maps hidden states back into the model’s input-embedding space, while persistent KV-cache working memory carries mixed text, latent reasoning, and tool observations across turns. HybridSFT and HybridRL train the model to coordinate these modes and decide when to reason silently versus interact visibly. On 4B–14B Qwen3-based models, the authors report improved results across 11 math, science, medical, search, and agentic benchmarks, alongside 35.5%–54.7% fewer tokens, faster inference, and lower estimated cost; the central significance is an attempt to combine latent reasoning’s efficiency with the auditability and tool compatibility of text-based agents.

Robots Still Need a Data Flywheel

construction-physics.com  ·  46 pts  ·  15 comments

Robot learning lacks the abundant, varied examples that made language-model scaling possible. Teleoperation, simulation, reinforcement learning, and human recordings each offer a partial answer, but the path from collected behavior to reliable generalization remains expensive and uncertain.

Read →Share →
[ Analysis + ]

Technical Analysis

The article examines the central data problem in training capable robots: unlike language models, robotics lacks a vast, readily available corpus of high-quality task examples. It surveys major collection methods—teleoperation, real-world reinforcement learning, simulation, synthetic data, and recordings of humans using cameras or robotic interfaces—along with their trade-offs in cost, realism, scalability, and the sim-to-real gap. Current robot datasets are growing rapidly but remain orders of magnitude smaller and less information-dense than those used for leading language models, potentially implying billions of dollars to collect enough data for comparable scaling. The issue matters because robotics progress may depend on building an effective data flywheel through deployment, while better architectures or general-purpose AI could reduce the amount of task-specific data required.

Technical Analysis
