The HN Take

Royalist cipher

A 370-year-old cipher has apparently been solved by Claude Fable 5.1 in 44 minutes and 176,000 tokens. The solution is impressive, historically plausible and, as the researchers note, "quite embarrassing for humans in hindsight."

Sir Thomas Urquhart's Cyphral Distich consists of two lines of 32 numbers. It appears immediately after 32 numbered passages called Proquiritations. Urquhart even writes that "there can no number like that of two and thirty ... be pitched upon." For each number in the cipher, Fable went to the corresponding Proquiritation, counted to that word and took its first letter. This produced:

"O GOD UPHOLD KING CHARLS THE SECOND AND

MAKE HIM THE SUPREME RULER OF THIS LAND"

Urquhart was a committed Royalist, so yes. He wrote 32 passages, emphasized the number 32, printed two rows of 32 numbers immediately afterward and promised that readers would find "his own heart's wishes." Cryptographers spent centuries looking for an external key. The key was the preceding pages saying, approximately, "please use these preceding pages as the key."

Fable then applied the same basic approach to a larger 285-number cryptogram in another Urquhart book, using each number as a word index into the corresponding numbered page. That yielded another mostly decoded Royalist prayer asking God to restore Charles II, with nine letters still unresolved and a one-page shift partway through. Apparently Urquhart had one secret message.

The grand AI story here is not that the model invented some unprecedented form of cryptanalysis. It noticed the extremely conspicuous clue and kept working through obscure old books. This is perhaps a useful model of artificial intelligence: Humanity has accumulated centuries of unsolved mysteries, some of which are profound, and some of which are sitting directly beside their own instructions.

386 in a Pico

Here is a modern computing project:

FRANK 386 emulates a 386 PC on an RP2350, the microcontroller used in the Raspberry Pi Pico 2. It offers "full i386 (and partially i486/i586) CPU emulation," up to 8 megabytes of RAM, VGA or HDMI output, floppy, hard-drive and CD-ROM images, Sound Blaster 16 audio, PS/2 or USB input and NES gamepad support. It boots DOS, Linux, Windows 3.x and Windows 95.

This is a pleasing direction for technological progress. We spent several decades making computers dramatically faster and smaller, and have now achieved a tiny computer powerful enough to pretend to be a much larger, dramatically worse computer.

There are some compatibility details. If Windows 95 setup reports "0 bytes of memory," the instructions say to use "setup /im" to bypass the memory check. If Windows produces a protection error at startup, use patcher9x. The RP2350 can run at 504 megahertz so that it can convincingly emulate a 386, which Windows 95 then rejects for being confusingly futuristic. Progress marches backward.

Analysis

By recognizing that the numerical cipher relied on a word-indexing system within the book itself—rather than complex external encryption—the model reconstructed a hidden Royalist prayer for King Charles II. This achievement also extended to Urquhart’s "Cyphral Octastick," demonstrating the model's ability to cross-reference historical texts and identify context-dependent patterns that had previously eluded human researchers. The success highlights how AI can efficiently overcome the human attention bottlenecks inherent in historical research by persistence in testing disparate, non-standard approaches to archival puzzles.

Analysis

The "FRANK 386" project is an x86 PC emulator designed to run on the Raspberry Pi Pico 2 (RP2350) microcontroller. Based on the Tiny386 emulator, the firmware allows supported boards—such as the Murmulator or Olimex PICO-PC—to boot legacy operating systems like DOS, Windows 3.x, and Windows 95. It features support for up to 8MB of RAM, VGA/HDMI output, and various sound standards like AdLib and Sound Blaster 16 using the RP2350’s processing capabilities. This project is significant for the retro-computing community, as it demonstrates the feasibility of high-fidelity legacy PC virtualization on affordable, modern microcontroller hardware.

6. An atlas of periodic solutions to the three-body problem

threebodyorbits.com | danielmorozoff | 26 points | 0 comments | discussion

First seen: September 14, 2026 | Consecutive daily streak: 1 day

Analysis

"Three Body Orbits" is an interactive digital atlas that catalogs 3,915 unique periodic solutions to the classical three-body problem in orbital mechanics. While the three-body problem lacks a general analytical solution due to its chaotic nature, these specific periodic configurations demonstrate stable, repeating paths where masses return to their original positions and velocities. The project visualizes these complex mathematical relationships by grouping similar orbits together on a navigable map, allowing researchers and enthusiasts to explore distinct families of motion. By providing a structured, accessible database of these non-intuitive orbits, the atlas serves as a valuable resource for studying the dynamics of gravitational systems that would otherwise be difficult to conceptualize.
