TileLang is a Pythonic domain-specific language for writing high-performance GPU, CPU, and NPU kernels such as GEMM, dequantization, FlashAttention, and other AI workloads. It combines concise tile-oriented programming with low-level controls for memory movement, layouts, synchronization, pipelines, tensor cores, and warp or SIMD execution. Built on Apache TVM and its intermediate representations, TileLang compiles these programs through optimization and lowering passes into device-specific code. The project includes autotuning, persistent tile scheduling, backend registries, profiling, IR inspection, source-aware diagnostics, and debugging tools for analyzing compiler transformations. Its expanding backend support covers CUDA, ROCm, Metal, LLVM-based CPU execution, and Huawei Ascend hardware, with specialized paths for modern accelerator features and numerical formats.

TileLang is particularly useful for compiler engineers, kernel developers, researchers, and AI framework teams that need near-hand-tuned performance without implementing every kernel directly in vendor-specific languages. It provides a productive way to experiment with optimized kernels while retaining explicit control over hardware behavior and enabling reuse across supported architectures. Researchers working on transformer inference, attention mechanisms, quantized models, and emerging accelerator designs can benefit from its growing library of examples and specialized primitives.
